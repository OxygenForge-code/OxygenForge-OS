Server · x86_64

Konsolda güvenli bir sunucu.

OxygenForgeOS Server; masaüstü yüklemeden, varsayılan olarak kapalı SSH, nftables ve fail2ban ile gelir. Kurulumdan sonra yalnızca gerçekten ihtiyacın olan servisleri aç.

Sunucu rehberi · Sürüm 1.0 · Türkçe

Server ISO · x86_64 OxygenForgeOS-server-x86_64.iso 1.1 GB · UEFI + BIOS · SHA-256 ile doğrula
ISO indir → SHA-256

Önce oku: SSH varsayılan olarak kapalıdır ve güvenlik duvarı 22/tcp’yi açmaz. Uzak sunucuya kurulum yapıyorsan konsol/console erişimin olduğundan emin ol.

1. Canlı oturumda kurulum

ISO’dan açılan konsolda grafik Calamares kurulumunu başlat:

sudo oxygenforge-installer

Kurulum bittiğinde X ve Calamares hedeften kaldırılır; sistem konsol tabanlı kalır.

2. İlk kontroller

Kurulumdan sonra temel durumu doğrula:

cat /etc/os-release
systemctl status nftables systemd-resolved
sudo nft list ruleset
resolvectl status
systemctl status ssh

ssh servisinin inactive olması beklenir. Bu bir hata değil, bilinçli varsayılandır.

3. SSH’ı güvenli açma

Önce kullanıcı parolanı ve tercihen bir SSH anahtarını hazırla. Anahtar kullanacaksan parola girişini kapat:

sudo systemctl enable --now ssh
sudo nft list ruleset

Güvenlik duvarında 22/tcp’ye izin vermek için /etc/nftables.conf içindeki chain input bloğuna ekle:

tcp dport 22 accept

Ardından kuralları yeniden yükle ve fail2ban’i kontrol et:

sudo systemctl restart nftables
sudo systemctl status fail2ban
sudo fail2ban-client status sshd

4. Gizlilik ayarları

DNS-over-TLS ve gelen bağlantı güvenlik duvarını komut satırından yönet:

sudo /usr/libexec/oxygenforge-privacy-helper dns on
sudo /usr/libexec/oxygenforge-privacy-helper dns off
sudo /usr/libexec/oxygenforge-privacy-helper firewall on
sudo /usr/libexec/oxygenforge-privacy-helper firewall off

Varsayılan DNS Quad9’dur (9.9.9.9 / 2620:fe::fe) ve DNS-over-TLS kullanır. Değiştirmek için Gizlilik Merkezi yardımcısını veya systemd-resolved yapılandırmasını kullan.

5. Sertleştirme kontrol listesi

  • SSH için parola yerine anahtar kullan; PasswordAuthentication no yap.
  • Yalnızca gereken portları aç; varsayılan drop politikasını koru.
  • Düzenli yedek al; LUKS kullanıyorsan kurtarma anahtarını cihazdan ayrı sakla.
  • Otomatik güncelleme varsayılan kapalıdır; ayda bir apt full-upgrade ve yeniden başlatma planla.
  • Sunucuya masaüstü kurma; saldırı yüzeyini büyütür.
  • İzleme gerekiyorsa yalnızca kendi denetlediğin uç noktaya veri gönder.

6. Güncellemeler

sudo apt update
sudo apt full-upgrade
sudo needrestart

Otomatik güvenlik güncellemesi bilinçli bir tercihtir ve düzenli ağ bağlantısı gerektirir. Varsayılan olarak açık değildir.
