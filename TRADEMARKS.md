**Last updated:** November 8, 2026

The following names and visual identities are associated with OxygenForge and/or its official projects:

- **OxygenForge**
- **OxygenForgeOS**
- **OxygenForge OS**
- **OxygenForge AI**
- Official OxygenForge logos, icons, and visual branding

The Apache License 2.0 grants rights to the software code. It does **not** grant permission to use OxygenForge trademarks as if a project, product, service, or distribution were officially provided, endorsed, or maintained by OxygenForge.

## 2. What You Can Do

You may:

- Fork OxygenForgeOS.
- Modify the OxygenForgeOS source code.
- Redistribute modified versions in accordance with the Apache License 2.0.
- Use the source code in personal, educational, commercial, and other projects permitted by the Apache License 2.0.
- Refer to OxygenForgeOS for compatibility, attribution, or historical purposes.
- State that your project is "based on OxygenForgeOS" or "a fork of OxygenForgeOS", provided that the statement is accurate and does not imply official affiliation.

## 3. Forks and Modified Versions

Forks and modified versions are welcome.

However, modified versions should not use the **OxygenForge** or **OxygenForgeOS** name, logo, or branding in a way that could reasonably make users believe that the modified version is an official OxygenForge release.

For example, a project may describe itself as:

> "An unofficial fork of OxygenForgeOS."

It should not present itself as:

> "The official OxygenForgeOS release."

unless it has explicit permission from the OxygenForge project maintainers.

## 4. Renaming Modified Distributions

If you distribute a substantially modified version of OxygenForgeOS as a separate operating system or distribution, you are encouraged to use a different product name and branding.

Changing the name and visual identity helps users clearly distinguish the original OxygenForgeOS project from independently maintained derivatives.

The underlying source code may remain licensed under the Apache License 2.0, subject to the terms of that license.

## 5. Logo and Visual Identity

The official OxygenForge logos, icons, artwork, and other distinctive branding are not automatically licensed under the Apache License 2.0 merely because they are included in the source repository.

Do not:

- Modify the official OxygenForge logo and present it as an official logo.
- Use OxygenForge branding as the primary identity of an unofficial distribution.
- Create misleading websites, downloads, installers, or stores that appear to be operated by OxygenForge.
- Use OxygenForge branding in a way that implies endorsement, sponsorship, partnership, or official status without permission.

## 6. Commercial Use

Commercial use of the **OxygenForgeOS source code** is permitted according to the Apache License 2.0.

However, commercial use of OxygenForge trademarks must not imply that the commercial product is official, endorsed, sponsored, or maintained by OxygenForge unless permission has been granted.

For example, a company may build a commercial product using OxygenForgeOS source code under the Apache License 2.0, but it should use its own product name and branding unless it has permission to use OxygenForge trademarks.

## 7. Compatibility and Attribution

Truthful descriptive use of the OxygenForge name is allowed.

Examples include:

- "Compatible with OxygenForgeOS."
- "Based on OxygenForgeOS."
- "Forked from OxygenForgeOS."
- "Uses components from OxygenForgeOS."

Such statements must not be presented in a manner that suggests official affiliation.

## 8. Package Names and Technical Identifiers

Technical identifiers such as package names, namespaces, repository names, domain names, application IDs, or similar identifiers containing "OxygenForge" should not be used to impersonate official OxygenForge projects.

Official OxygenForge identifiers should not be reused for unrelated projects.

Where technically practical, independent forks should use their own identifiers.

## 9. Official Releases

Only releases published through official OxygenForge channels or explicitly authorized maintainers should be represented as official OxygenForge releases.

Third-party builds, mirrors, forks, and modified distributions should clearly identify themselves as unofficial where there is a reasonable possibility of confusion.

## 10. No Implied Endorsement

Use of OxygenForge software does not imply:

- Endorsement by OxygenForge.
- Sponsorship by OxygenForge.
- Partnership with OxygenForge.
- Official maintenance by OxygenForge.
- Certification by OxygenForge.

Permission to use the source code under Apache License 2.0 should not be interpreted as permission to use the OxygenForge brand.

## 11. Reporting Trademark Concerns

If you believe a project, website, distribution, application, or other product is using OxygenForge branding in a misleading or unauthorized manner, please contact the OxygenForge maintainers through the official project channels.

Please provide:

1. The location where the trademark is being used.
2. A description of the potentially confusing use.
3. Why you believe the use may imply an official relationship.
4. Any relevant screenshots or links.

## 12. Permission Requests

If you would like to use OxygenForge trademarks beyond the uses described in this policy, please contact the OxygenForge project maintainers.

Permission may be granted on a case-by-case basis.
